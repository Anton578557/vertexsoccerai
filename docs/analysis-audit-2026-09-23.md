# Проверка анализатора — 23 сентября 2026

## Что изменено

- Vertex Model 2.1: null/пустые значения больше не равны нулю дней отдыха. Отрицательные и отсутствующие показатели голов не дают прогноз.
- Расчёт распределения расширен до 16 голов на команду; тест аналитического распределения Пуассона покрывает весь диапазон интенсивностей модели.
- Отчёт: исходы, двойной шанс, без ничьей, тоталы 0.5–5.5, голы команд 0.5–2.5, обе забьют, сухой матч, пять счетов. Все вероятности используют одно распределение. Условные вероятности без ничьей подписаны отдельно.
- Словарь русских/испанских названий и официальных названий поставщиков расширен; одно общее слово не определяет идентичность команд.
- Сопоставление турниров учитывает страну. Primera División из Перу/Боливии не получает испанские базовые показатели.
- Перепутанные хозяева/гости исправляются по подтверждённому расписанию до построения модели.
- История Football-Data и проверка результатов используют только FINISHED, счёт за 90 минут. Неподтверждённый счёт после дополнительного времени исключается.
- Первый прогноз до начала матча сохраняется неизменным; повторный запрос не стирает оценённый результат. Начавшиеся матчи не включаются в предматчевую оценку.
- Отдельная частота попаданий и бинарная ошибка Brier для выбранного исхода каждого рынка; общий процент по пересекающимся рынкам больше не выдаётся за точность модели.

## Проверка

`node --test tests/*.test.js`: 30 успешных тестов на момент подготовки релиза. Проверены языки, отсутствие данных, разделы отчёта, экранирование текста, идентичность клубов, математика и сохранение прогнозов. `node --check`: 52 рабочих JS-файла. Тестовые примеры синтетические и не являются бэктестом.

## Что известно о качестве прогнозов

На момент read-only проверки базы: 5 матчей с сохранёнными прогнозами, 1 матч с оценённым результатом (4 рынка). Это не позволяет установить качество, доходность или калибровку вероятностей.

Модель использует заданные вручную веса и коэффициент Dixon–Coles. Индекс уверенности и полнота данных не являются точностью. Исторические записи не имеют версии модели; их нельзя объявлять результатами версии 2.1. Старые данные не переписывались.

Поиск зависит от словаря и покрытия поставщиков. Для малых лиг может не хватать истории даже после правильного определения клуба. Угловые, карточки, удары показываются лишь при наличии статистики; оценка забитого пенальти не равна вероятности назначения пенальти. Наличие минимум трёх игр — технический порог, а не доказательство достаточности выборки.

Следующая обоснованная проверка качества: неизменяемые предматчевые снимки с версией модели, много завершённых независимых матчей, хронологический тест без будущих данных, сравнение Brier/калибровки с простыми базовыми моделями по лигам и рынкам. Само увеличение числа вариантов точность не повышает.
