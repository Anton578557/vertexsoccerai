# Автоматизация источников — 23 сентября 2026

Продолжение `pipeline-audit-2026-09-23.md`. Постоянные цели владельца находятся в `PROJECT-BRIEF.md`.

## Фактические изменения

- Wikidata включён как резервный многоязычный справочник клубов. Неизвестный русскоязычный ввод больше не ограничивается транслитерацией. Принимается только однозначное соответствие; страницы сезонов, игроки и стадионы исключены.
- OpenFootball подключён к анализатору как резерв завершённых результатов. Настроены текущие открытые наборы Англии (два дивизиона), Германии, Испании, Италии, Франции, Нидерландов, Португалии и Бразилии A. Бразилия B и Колумбия не заявляются как покрытые: актуальных наборов 2026 года в проверенных репозиториях нет.
- Добавлен адаптер истории Sportmonks с проверкой состояния матча, счёта за 90 минут и ограниченной пагинацией. Успешный ответ `/leagues` больше не считается доказательством покрытия конкретных клубов. Пустой поиск означает `teams_unavailable`, а не доказанную причину в тарифе.
- ESPN проверен с Vercel и вернул HTTP 403. Экспериментальный адаптер отключён по умолчанию. Его нельзя считать рабочим резервом; включение требует отдельно подтверждённого доступа (`ESPN_FOOTBALL_ENABLED=true`).
- Сохранены кэш, автоматический переход к резервам, тайм-ауты и паузы после отказов поставщиков. Обновление истории выполняется автоматически при запросе с истекшим общим кэшем. Это не обещание непрерывного live-feed.
- История исключает будущие/устаревшие матчи, неполные счета и конфликтующие дубли. Расписание двух команд не выдаётся за репрезентативную выборку всей лиги. В OpenFootball с датами без часового пояса исключён текущий календарный день.
- Наутико, Спорт Ресифи, Медельин и Мильонариос получают реальные идентификаторы и эмблемы. Исправлено сопоставление сокращений F.C./C.D. и фильтрация резервных команд в подсказках.
- Отчёт различает нераспознанную команду и недостаток доступных данных. Для распознанных команд с ограничениями источников повторный ввод названий не предлагается как решение.
- Новости River Plate, использующие прозвище Millonarios, исключаются из контекста колумбийского клуба без дополнительного подтверждения. Непроверенные новости не меняют модель.

Дополнительно парсер обработал настоящий текущий JSON OpenFootball: 50 завершённых матчей, по 5 для Arsenal/Chelsea; runtime объединяет текущий и предыдущий сезоны.

## Алгоритм и ориентир Foresportia

Изучены открытые описание и методология Foresportia. Приняты ориентиры: согласованные вероятности разных рынков, объяснение данных и ограничений, проверяемая история предматчевых прогнозов, калибровка по лигам. Самостоятельно заявленные проценты другого сайта не считаются сопоставимым независимым бенчмарком.

Численные коэффициенты Vertex v2.2 в этой работе не менялись. Предыдущий честный тест 200 игр Аргентины не подтвердил преимущество над частотами лиги (Brier 0.65699 против 0.65696). Удалено неподтверждённое обещание точности 80%+ из README. Для доказанного улучшения нужны отдельные обучающие и контрольные периоды по нескольким лигам; нельзя подгонять модель под уже просмотренные результаты.
