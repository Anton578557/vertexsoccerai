## Что добавлено

- OpenLigaDB: реальный адаптер завершённых результатов официальных немецких лиг bl1/bl2/bl3. Ранее источник был только зарегистрирован в списке и проверялся запросом списка лиг. Теперь участвует в автоматическом резерве анализатора; диагностика проверяет историю Bayern/Dortmund.
- BSD / Bzzoiro Sports Data: подготовлен серверный адаптер бесплатного Football REST v2. Без ключа не делает запросов. После ключа тоже выключен до отдельной проверки (`BSD_FOOTBALL_ENABLED=true`). Наличие подготовленного кода не означает, что источник уже подключён.
- Кэш общих запросов, ограниченная пагинация, тайм-ауты; у BSD остановка после отказа доступа или квоты, с учётом Retry-After и сброса дневной квоты в UTC. Ключ передаётся только серверным заголовком Authorization; в URL, публичный статус и репозиторий не попадает.
- Данные принимаются только при точной идентификации, завершённом статусе и проверяемых 90-минутных результатах. Половина матча, дополнительное время, пенальти и предполагаемые составы не подменяют эти значения. Два расписания команд не считаются полноценной выборкой лиги.
- Новые зависимости в анализаторе, статусе поставщиков и диагностике; версии кэша analysis-core:v12 / system-diagnostics:v8.

## Как завершить BSD без расходов

1. Бесплатная регистрация владельца: https://goaldir.com/register/?next=/dashboard/ . Подтвердить почту. Пароль и код подтверждения — только через защищённый механизм авторизации, не через чат.
2. Полученный ключ сохранить в Vercel как серверную переменную `BSD_API_KEY`. Не помещать в клиентский JS, git, логи или переписку. Не включать платные add-ons.
3. Оставив `BSD_FOOTBALL_ENABLED` выключенным, выполнить `/api/provider-check`: диагностический адаптер проверит реальные истории Nautico/Sport Recife и Independiente Medellin/Millonarios, точные идентификаторы, формат счёта и свежесть. Если API отличается от подготовленной документированной схемы, адаптер откажет; уточнить по настоящему ответу, не ослабляя проверки.
4. Только после успешного результата включить `BSD_FOOTBALL_ENABLED=true`, обновить deployment и кэш анализов. Проверить обе пары через авторизованный интерфейс RU/ES. Никаких обещаний покрытия на основании одного наличия лиги в каталоге.
