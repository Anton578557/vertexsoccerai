## Исправления

- Расинг/Rasing → Racing Club, Блаублитц → Blaublitz Akita, Албирекс Ниигата → Albirex Niigata. Добавлены названия из CSV.
- Поиск метаданных проверяет идентичность команды и вид спорта. Для проверенных проблемных клубов применяется lookup по ID: поиск Nottingham Forest возвращал нетбольную команду с тем же названием.
- Резерв Football-Data.co.uk теперь подаёт свежие результаты в основную модель. Поддержаны международные столбцы Home/Away/HG/AG и лиги ARG/BRA/MEX/USA/JPN, с проверкой страны и дивизиона. Японская J2 не подменяется J1.
- Формы/домашние и гостевые показатели/базовые частоты лиги строятся по одному выбранному набору данных. В отчёте доступны использованные матчи.
- Исключены пустые, отрицательные и некорректные счета, дубли, текущий день CSV, будущие матчи и устаревшая история. Не менее трёх игр каждой команды; последняя игра не старше 90 дней для открытого резерва.
- Пустые угловые/карточки/удары больше не считаются нулевыми; событийный рынок требует минимум трёх наблюдений каждой команды. Исправлено и сохранение этой статистики.
- Точное сопоставление команд применяется также к API-Football и сведениям об отсутствующих игроках. Текущий счёт/дополнительное время не принимаются за подтверждённые 90 минут.
- Исправлена обратная ориентация хозяев/гостей в резервном расписании.
- Погода Peru, US для перуанского клуба больше не учитывается; неизвестная температура не равна 0°C.
- Для исчерпанной квоты и приостановленного аккаунта введены общие паузы в кэше. Они не снимают ограничения поставщика и не меняют тариф.
- Диагностика показывает degraded при недоступности резервных источников и проверяет фактическое получение истории, а не только HTTP 200.
- Эмблемы имеют устойчивое место и резервный значок с инициалами при отсутствии/ошибке изображения.

## Проверка качества численной модели

`node scripts/audit-history.js /path/to/ARG.csv`

Последовательная ретроспективная проверка последних 200 доступных матчей Аргентины (20.04–22.09.2026). На каждом шаге используются только предшествующие дни, результат проверяемого матча и более поздние матчи исключены. Сопоставление с базовой моделью частот 1X2 той же лиги, рассчитанных на предшествующей истории.

| Метрика | Vertex | Частоты лиги |
| --- | ---: | ---: |
| Brier 1X2, сумма трёх квадратов (меньше лучше) | 0.65699 | 0.65696 |
| Доля верно выбранного наиболее вероятного исхода | 38.5% | 42.0% |

Преимущество текущих коэффициентов не подтверждено. Это проверка численной части на одной лиге, без недоступных исторических новостей/погоды/составов, с округлёнными выходными вероятностями, не проспективная история сервиса. Нет оснований заявлять общую точность или доходность. Коэффициенты не подгонялись под эту контрольную выборку. Для улучшения качества нужны отдельные обучающие и контрольные периоды, несколько лиг и неизменяемые предматчевые снимки с версией модели. Исторические записи в базе не переписывались.
